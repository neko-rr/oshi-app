# ブランド既定色の種（初学者向け）

## いちばん大事なこと

顧客が選ぶ **テーマ色** と、開発が決める **ブランドの種** は別です。

- **テーマ色** … ユーザーが選ぶとアプリのセマンティック色トークン一式が切り替わる色・パック（[themes.md](themes.md)）。既定は緑系 `default`  
- **ブランドの種** … 案内サイトや将来のブランド印象の出発点（いまは `#9f606c`。スケール詳細は後回し）

## いま決まっていること

| 項目 | 内容 |
|------|------|
| アプリ既定テーマ | 緑系 `default`（`colors.css` の `:root`） |
| ブランド種の色 | `#9f606c`（落ち着いたローズ系・スケールは後回し） |
| 作った場所 | [UI Colors（generate/9f606c）](https://uicolors.app/generate/9f606c) |
| 部品の土台 | [shadcn/ui](https://ui.shadcn.com/) |

「種」とは、一色から薄い色〜濃い色の階段（スケール）を後で作るときの **基準の一色** です。  
いまは **種だけ覚えておけば十分** です。アプリの日常の既定見た目は **緑系テーマ**。

## まだやらないこと（後回し）

- 50 / 100 / … / 950 のような **色の階段の一覧を文書に書く**  
- その階段をそのまま `colors.css` に全部書き込む  

理由: 先に UI/UX・動き・テーマ選びやすさを固め、色の細かい階段は Design Lab で見比べてから決めるため。

## いつスケールを書くか

フェーズ1（トークン反映）のとき:

1. UI Colors などで `#9f606c` からスケールを出す  
2. 必要なら shadcn のセマンティックに対応づける  
3. このファイルに「対応表」を追記する  

## 混同しないで

| 名前 | 用途 |
|------|------|
| 緑系 `default` | アプリの既定テーマ（todo-app 方式のトークン一式） |
| ブランドの種 `#9f606c` | 将来のブランド印象の出発点（開発・後回し） |
| テーマ色 | ユーザーが選ぶ見た目パック（多数可） |
| カラータグ | 製品に付ける色ラベル（別機能・枠数は現状維持） |
