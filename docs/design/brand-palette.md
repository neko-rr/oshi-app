# ブランド既定色の種（初学者向け）

## いちばん大事なこと

顧客が選ぶ **推し色** と、開発が決める **ブランドの種** は別です。

- **推し色** … ユーザーが「自分の推しの色」をタップしてアプリのアクセントに反映する色  
- **ブランドの種** … まだ推し色を選んでいないときや、案内サイト・既定テーマで使う「oshi-app らしい色の出発点」

## いま決まっていること

| 項目 | 内容 |
|------|------|
| 種の色 | `#9f606c`（落ち着いたローズ系） |
| 作った場所 | [UI Colors（generate/9f606c）](https://uicolors.app/generate/9f606c) |
| 部品の土台 | [shadcn/ui](https://ui.shadcn.com/) |

「種」とは、一色から薄い色〜濃い色の階段（スケール）を後で作るときの **基準の一色** です。  
いまは **種だけ覚えておけば十分** です。

## まだやらないこと（後回し）

- 50 / 100 / … / 950 のような **色の階段の一覧を文書に書く**  
- その階段をそのまま `colors.css` に全部書き込む  

理由: 先に UI/UX・動き・推し色の選びやすさを固め、色の細かい階段は Design Lab で見比べてから決めるため。

## いつスケールを書くか

フェーズ1（トークン反映）のとき:

1. UI Colors などで `#9f606c` からスケールを出す  
2. shadcn の `--primary` などに対応づける  
3. このファイルに「対応表」を追記する  

## 混同しないで

| 名前 | 用途 |
|------|------|
| ブランドの種 `#9f606c` | アプリ全体の既定トーン（開発） |
| 推し色 | ユーザーが選ぶアクセント（多数） |
| カラータグ | 製品に付ける色ラベル（別機能・枠数は現状維持） |
