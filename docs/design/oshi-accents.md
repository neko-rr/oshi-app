# 推し色・テーマ色（顧客が選ぶ見た目）

## 目的

グッズや好みに合わせて、アプリの **見た目色** を自分用にできること。  
実装の正本は [themes.md](themes.md)（[todo-app](https://github.com/neko-rr/todo-app) 方式）。

## カラータグとの違い（重要）

| | テーマ／推し色（この文書） | カラータグ |
|--|---------------------------|------------|
| 用途 | アプリ全体のセマンティック色 | 製品に付ける色ラベル |
| UI | `/settings/theme` など | `/settings/color-tags` |
| 枠数 | テーマパック（多数可） | **現状のまま（変更しない）** |

**統合しない。** 用途が違う。

## 顧客向け UX

1. テーマを選ぶと **全部品の色トークン**が切り替わる（背景・文字・ボタン等）  
2. コンポーネントに色名／hex を直書きしない  
3. 既定は **緑系 `default`**  
4. 選んだ結果はすぐ反映され、サーバー（`theme_settings`）に保存される  

## 反映範囲

| 変えてよい | 変えない（原則） |
|------------|------------------|
| `colors.css` のセマンティック変数一式 | 部品への `#RRGGBB` 直書き |
| `data-theme` によるパック切替 | カラータグの枠数・用途 |

※ 「`--primary` / `--ring` だけ」は **採用しない**（誤りだった記述の訂正）。

## ブランド既定

未選択時・初回・不明な旧テーマ名は **緑系 `default`**。  
ブランド種 `#9f606c` のスケール詳細は [brand-palette.md](brand-palette.md) どおり後回し。

## 実装メモ

- 保存: FastAPI `GET/PUT /theme-settings`
- UI: `/settings/theme`（`ThemePicker`）
- トークン定義: `apps/web/src/styles/colors.css`
- Dash/Bootswatch テーマ名は廃止

## Do / Don't

| Do | Don't |
|----|-------|
| セマンティック名だけで部品を書く | 画面に hex／色名を直書きする |
| テーマでトークン一式を切り替える | カラータグとテーマを混ぜる |
| 既定を緑系 `default` にする | 旧 Bootswatch ID を正にする |
