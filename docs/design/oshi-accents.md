# 推し色・テーマ色（顧客が選ぶ見た目）

## 目的

グッズや好みに合わせて、アプリの **見た目色** を自分用にできること。  
実装の正本は [themes.md](themes.md)（テーマパック）と本ファイル（推し色オーバーレイ）。

## カラータグとの違い（重要）

| | テーマ／推し色（この文書） | カラータグ |
|--|---------------------------|------------|
| 用途 | アプリ全体のセマンティック色 | 製品に付ける色ラベル |
| UI | `/settings/theme` など | `/settings/color-tags` |
| 枠数 | テーマパック（多数可）＋推し色2ロール | **現状のまま（変更しない）** |

**統合しない。** 用途が違う。

## 二層モデル

| 層 | 役割 | 保存 |
|----|------|------|
| **テーマパック** | 背景・文字・カード等のトークン**一式**を `data-theme` で切替 | `theme_settings` |
| **推し色** | パックの上に載せる **メイン＋サブ** の2色オーバーレイ | `oshi_accent_settings`（適用はプレミアム想定） |

- **メイン** → 主ボタン・フォーカスリング（`--primary` / `--ring` / `--primary-foreground`）
- **サブ** → やわらかい面・チップ下地（`--accent` / `--oshi-soft`）。**キャンバス全体の `--background` はテーマパックのまま**（全面染めしない）

テーマ自体を「`--primary` だけ差し替え」で済ませるのは誤り（[themes.md](themes.md)）。  
推し色レイヤが primary／accent を上書きするのは **別機能**であり、両立する。

## 顧客向け UX

1. テーマを選ぶと全部品の色トークンが切り替わる（既定は緑系 `default`）— **設定画面では常に素のパックが全体に出る**
2. 推し色は「メイン（ボタンなど）」「サブ（やわらかい背景）」をスウォッチ／HEX で選ぶ
3. **既定のプレビューは見本ボックス内のみ**（ページ全体の `--primary` は上書きしない）
4. 「アプリ全体で試し見」は **OFF 既定の明示トグル**。ON 中はテーマのボタン色が一時的に隠れる旨を表示
5. **文字色は自動**（白／濃色／色のライト・ダーク派生から WCAG AA 4.5:1 を満たすものを選ぶ）
6. 無料: **見本プレビュー可・全体適用と保存はロック**（プレミアム想定）
7. 有料: 適用ON、プリセット最大 **3組**

## 反映範囲

| 変えてよい | 変えない（原則） |
|------------|------------------|
| テーマパックのセマンティック変数一式 | 部品への `#RRGGBB` 直書き |
| 推し色ON時の primary / ring / accent（限定） | カラータグの枠数・用途 |
| | キャンバス `--background` を推し色で全面置換 |

## ブランド既定

未選択時・初回・不明な旧テーマ名は **緑系 `default`**。  
推し色未適用時はテーマパックの primary／accent のまま。  
ブランド種 `#9f606c` のスケール詳細は [brand-palette.md](brand-palette.md) どおり後回し。

## 実装メモ

- テーマ保存: FastAPI `GET/PUT /theme-settings`
- 推し色: FastAPI `GET/PUT /oshi-accent-settings`（`entitled` ゲート）
- UI: `/settings/theme`（`ThemePicker` + `OshiAccentPanel`）
- コントラスト: `apps/web/src/lib/oshiContrast.ts` / API `oshi_contrast.py`
- トークン定義: `apps/web/src/styles/colors.css`＋推し色注入
- Dash/Bootswatch テーマ名は廃止

## Do / Don't

| Do | Don't |
|----|-------|
| セマンティック名だけで部品を書く | 画面に hex／色名を直書きする |
| テーマはトークン一式、推し色は2ロール | カラータグとテーマ／推し色を混ぜる |
| 文字色を自動選定し AA を満たす | 読めない組み合わせを保存・適用する |
| 既定を緑系 `default` にする | 旧 Bootswatch ID を正にする |
