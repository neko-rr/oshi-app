# ボイス・コピー（20〜30代・大人の推し活）

対象: アプリ内の **日本語ユーザー向け文言**（ボタン・空状態・エラー・ヒント）。  
英語は ja 正本に合わせて下書き（skill `i18n-web-sync`）。  
マスコット絵のトーンは [mascot-asset-brief.md](mascot-asset-brief.md)。動きは [motion.md](motion.md)。

## 北極星

> **静かで信頼できる。短く次の一手が分かる。**  
> 熱量はユーザーの中にある。UIコピーで煽らない・幼児化しない・晒さない。

| 目指す | 避ける |
|--------|--------|
| です・ます（または体言止めの短文） | 「〜だよ♪」「〜しちゃう？」 |
| 事実＋次の操作 | 感嘆符の連打・絵文字だらけ |
| 自分のコレクションを守る言い方 | SNS比較・「みんなは」「晒す」 |
| 失敗しても責めない | 「まだ何も登録してないの？」 |

## 推し語・スラング

| 層 | 方針 |
|----|------|
| **本線 UI**（ナビ・設定・エラー・主ボタン） | **一般語優先**（登録・検索・収納・見た目） |
| **任意の感情点**（空状態の一言・祝福の短い文） | 推し語は **ごく少量**可。なくても成立する文にする |
| **禁止の寄せ方** | 「尊い」「神」「沼」「同担拒否」などを **常時ラベルやナビに使わない** |

製品用語の正は `docs/product/` / glossary。ワイヤキーは英語 `snake_case` のまま。

## 絵文字・記号デコ

| Do | Don't |
|----|-------|
| 必要なら **1画面に0〜1個**まで（必須ではない） | ボタン・タブ・見出しに絵文字を並べる |
| lucide アイコン（[icons.md](icons.md)） | 絵文字を UI アイコン代わりにする |
| ♡ 等をブランドの顔にしない | ハート・星の乱発で「かわいい」を表現する |

## 空状態

構成はいつも同じ:

1. **短い事実**（何が空か）  
2. **次の一手**（主CTAへ）  
3. （任意）マスコットは [mascots.md](mascots.md) の感情点ルールに従う  

| Do | Don't |
|----|-------|
| 「グッズがまだありません。写真から登録できます。」 | 「何も無いよ！早く登録してね♡」 |
| 「条件に合うグッズは見つかりませんでした。条件を変えてみてください。」 | 「ゼロ件www」「残念！」 |
| 主ボタンを1つ明示 | 空状態だけで終わる・煽りだけ |

## エラー・オフライン

| Do | Don't |
|----|-------|
| 何が起きたか＋ **再試行／戻る** | ユーザーのせいにする言い方 |
| 色＋テキスト（[a11y.md](a11y.md)） | 赤枠だけ |
| 短いフラッシュ／インライン | 長い説教ダイアログ |

## プライバシー（シェアしない前提）

このアプリの本線は **自分のグッズ管理**。調査上も「シェアしない聖域」需要が強い。

| Do | Don't |
|----|-------|
| 保存・整理・見返しを主語にする | 登録直後に「シェア」「投稿」「公開」を主CTAにする |
| 共有が必要なら **明示のユーザー操作**の先に置く | タイムライン前提の UI を勝手に足す |
| 「自分用」「この端末」など安心の言い方は可 | 「友達に見せよう」「バズらせよう」 |

## 画面別の目安

| 画面 | コピーの役割 |
|------|----------------|
| ギャラリー | 写真が主。ラベルは短く。空なら登録へ |
| 登録 | 手順が分かる。専門用語を避ける |
| 検索 | 結果0件は条件変更を促す |
| 設定 | 説明は1行。モード名は羞恥語にしない（「隠し」禁止→[principles.md](principles.md)） |
| Auth | 落ち着いた案内。エラーは原因が分かる |

## エージェント向け（強制の要約）

詳細命令は `.cursor/rules/design.mdc`。ここでの要約:

- 子供っぽい／煽り／絵文字だらけのコピーを新設するな  
- SNS共有を本線CTAにするな  
- 空状態は事実＋次の一手  
- 推し語はナビに常駐させるな
