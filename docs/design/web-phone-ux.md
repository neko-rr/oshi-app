# スマホ Web（店頭 UX）

対象は **ブラウザのスマホ幅**（`apps/web`）。店・棚の前で片手操作する想定。  
**Expo ネイティブは別契約**（skill `design-mobile`）。ここを正にしない。

製品の DoD・画面要否は `docs/product/`（例: `acceptance/responsive_web.md` / `flows/gallery.md`）。  
この文書は **見た目・操作を壊さないための横断ルール**。

## 前提

- 電波が弱い／一瞬オフラインになりうる  
- 主CTA・戻る・タブは親指が届く位置を優先  
- 写真の中身が判別できること＞枠を埋め尽くすこと（必要なら余白を許す）

## シェル

| ルール | 内容 |
|--------|------|
| ブレーク | 下部タブは **`lg` 未満（1024px）**。`md` に下げると横向きでタブが消える |
| タブ | ギャラリー／登録／検索／その他。横向きでも維持 |
| デスクトップ | `lg+` はトップナビ。下部タブなし |
| 例外 | 認証・`/dev` は下部タブなし |
| 重なり | 一括バー・固定 CTA はタブ＋ safe-area と被らせない |

採用: Lab A（[feedback/decisions.md](feedback/decisions.md) `responsive-shell-lab-a`）。

## 写真

| 面 | 方針 |
|----|------|
| 一覧グリッド／リスト | 既定 `cover`。設定「はみ出し少なめ」で `contain`（`gallery_image_fit`・端末間同期） |
| 一覧「大きめ」 | **常に `contain`**（横長の切りすぎ防止） |
| 詳細ヒーロー／ライトボックス | `contain`。拡大中はピンチ・+/- を優先 |

## 連続確認（詳細）

- 一覧から開いたときだけ、隣の製品へ **前後ボタン／横スワイプ／矢印キー**  
- **ライトボックス表示中は製品スワイプしない**（写真操作優先）  
- ディープリンクのみ（並びコンテキストなし）では隣ナビを出さない  
- 大げさなページめくり演出はしない（[motion.md](motion.md)）

## フィードバック・通信

| 種類 | 方針 |
|------|------|
| 成功（登録・保存・一括） | 画面上部の **短いフラッシュ**（約2秒）。別ライブラリの重いトーストを増やさない |
| API 失敗 | 文言＋**再試行**。オフライン推定時は電波案内を強調 |
| オフライン | 薄い常時バナー。復帰で消える |

## 履歴と保存ビュー

| 種類 | 置き場 | 用途 |
|------|--------|------|
| 最近使った条件 | 端末 localStorage（最大8） | 同じタグ／収納の繰り返し。ギャラリー＋検索で共有 |
| 保存ビュー | サーバー（名前付き・上限あり） | 長く使う名前付きセット |

混同して片方を消したり「最近」をサーバー必須にしない。

## 店頭・屋外での見え方

棚前・明るい店内を想定する（[a11y.md](a11y.md) の低輝度／屋外ヒントと併用）。

| Do | Don't |
|----|-------|
| 写真判別と主CTAのコントラストを優先 | 薄い文字や弱いボーダーだけに頼る |
| トーン「落ち着き」でも操作が読めること | 店頭向けにマスコット常駐で画面を埋める |
| 文字サイズ設定・ブラウザ拡大を妨げない | 固定 px の小さい字で詰める |

## エージェント向け Do / Don't

| Do | Don't |
|----|-------|
| タブ・固定バーの余白に safe-area と `lg` を意識する | ブレークを `md` に戻す |
| 横長写真を切る変更の前に contain／large ルールを確認 | 一覧を全部 cover 固定に戻す |
| 成功は短いフラッシュ、失敗は再試行導線 | 成功ダイアログや長い祝福を本線に足す |
| 隣スワイプとライトボックス操作を分離する | 拡大中も製品遷移する |
| コピーは [voice.md](voice.md)（煽らない） | 店頭向けに絵文字だらけの案内 |
