# 動き（モーション）

女性らしさ・推し活の「気持ちよさ」は、色より **触ったときの反応** で作る。  
ただし本アプリの主目的はグッズの登録・検索・整理であり、**動きそのものを見せるアプリではない**。

## 本番の方針（採用・2026-09-03）

| 種類 | 方針 |
|------|------|
| **分かりやすさのための短い動き** | **本番で使う**（押した／保存した／切り替わったが分かる） |
| **時間がかかる・飾りの動き** | **本番で使わない** |
| **遊びたっぷり常時 UI** | **本番の既定にしない**（ターゲットは実務モードで開くことが多い） |
| **アプリ設定「動きを控えめに」** | **今は作らない**（短い有用な動きをユーザーに全部切らせない） |
| **OS の視覚効果を減らす** | **追従する**（`prefers-reduced-motion` で装飾を切る＝a11y の安全網） |

### 推し活らしさの置き場所

- **本線（登録・ギャラリー・検索・設定）** — 短い反応＋テーマ色・余白・自分用設定で気持ちよさを出す  
- **特別な瞬間（将来可）** — 初回登録完了・件数達成・季節イベントなど、**短く・たまに・意味があるときだけ**祝福演出を足してよい  
- **別モード／Lab／イベント限定（将来可）** — 「華やか」はここに閉じる。常時オンの本線には載せない  

## 原則

1. **短い** — だいたい 150〜250ms。長い演出はしない  
2. **目的がある** — 押した／保存した／切り替わったが分かるためだけ  
3. **控えめ＋短い遊び心** — fade・わずかな scale・色のなめらかな変化。bounce・強いグローは避ける。アイコン選択など短い scale（`--motion-playful` 約 220ms）は可  
4. **減らしてもよい** — `prefers-reduced-motion` では装飾モーションを切る（本番の分かりやすさ用の動きも、OS が減らす指定なら切る）  

## 使う場面（本線）

| 場面 | 動きの例 |
|------|----------|
| ボタン押下 | ごく弱い押し込み（scale） |
| テーマ変更 | セマンティック色一式の短いクロスフェード |
| 保存完了 | 小さな成功表示（テキスト or アイコン） |
| ギャラリー | ホバーの軽い反応。カルーセル過剰は避ける |
| 画面遷移 | OS / Next の標準に寄せる。独自の大げさなページめくりはしない |

## 使わない（本線）

- 時間がかかる演出（長いフェード・大げさなページめくり）  
- 常時きらめき・パーティクル・ループアニメ  
- 注意を奪う点滅  
- 「推し活らしいから」と本線全体を遊び動きで埋め尽くすこと  
- アプリ内トグルで有用な短い反応まで一括オフにすること（OS 設定は別）  

## 実装メモ

- 実装: `apps/web/src/styles/motion.css`（`--motion-fast` / `--motion-normal` / `--motion-playful`）  
- `tw-animate-css` を使う場合も、上記の長さ・強さに合わせる  
- 祝福スポットや華やかモードを足すときは、本線と分離し Lab／採用手順を踏む
