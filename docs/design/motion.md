# 動き（モーション）

女性らしさ・推し活の「気持ちよさ」は、色より **触ったときの反応** で作る。

## 原則

1. **短い** — だいたい 150〜250ms。長い演出はしない  
2. **目的がある** — 押した／保存した／切り替わったが分かるためだけ  
3. **控えめ** — fade・わずかな scale・色のなめらかな変化。bounce・強いグローは使わない  
4. **減らしてもよい** — `prefers-reduced-motion` では装飾モーションを切る  

## 使う場面

| 場面 | 動きの例 |
|------|----------|
| ボタン押下 | ごく弱い押し込み（scale） |
| 推し色変更 | アクセント色の短いクロスフェード |
| 保存完了 | 小さな成功表示（テキスト or アイコン） |
| ギャラリー | 必要なら画像の穏やかな出現。カルーセル過剰は避ける |
| 画面遷移 | OS / Next の標準に寄せる。独自の大げさなページめくりはしない |

## 使わない

- 常時きらめき・パーティクル  
- 注意を奪うループアニメ  
- アクセシビリティを無視した点滅  

## 実装メモ（後で）

- 既存の `tw-animate-css` を使う場合も、上記の長さ・強さに合わせる  
- トークン化（`--motion-fast` 等）は Lab 採用後でよい
