# デザイン原則

推し活グッズ管理アプリ向け。対象は「今どきの推し活ユーザー」が気持ちよく使えること。  
**女性らしさ・推し活感は、色の決め打ちではなく UI/UX と動きで作る。**

## 原則（6つ）

1. **写真とグッズが主役** — 装飾より中身。ギャラリーは大きく、余白をケチらない。階層は下表。  
2. **やさしく、でも信頼できる** — かわいいだけで終わらせない。登録・設定は迷わず進める。コピーは [voice.md](voice.md)。  
3. **テーマ色はトークン一式** — 顧客がテーマを選ぶと背景・文字・カード・ボタン等のセマンティック色がまとめて切り替わる（[themes.md](themes.md) / todo-app 方式）。部品に hex を直書きしない。**用途最適案でもテーマ色は入れる。**  
4. **1画面・1仕事** — 次にやることが一目で分かる。ヘッダーに機能を詰め込みすぎない。  
5. **触って分かる** — 押下・保存・切替は**短い動き**で返す。時間がかかる演出や、本線の遊びたっぷり常時モーションはしない（詳細は [motion.md](motion.md)）。  
6. **店頭・片手でも次が分かる** — スマホ Web は棚の前・電波弱を前提にする。主操作は親指が届き、失敗したら再試行できる（詳細は [web-phone-ux.md](web-phone-ux.md)）。

### 情報階層（固定）

画面を作る・直すときは、上からこの順で強くする。下位のために上位を潰さない。

| 順 | 層 | 例 |
|----|-----|-----|
| 1 | **写真／グッズ本体** | ギャラリー画像、登録プレビュー |
| 2 | **識別情報** | 名前・作品・タグ |
| 3 | **メタ** | 金額・日付・収納 |
| 4 | **クロム** | ナビ・ツールバー・マスコット・祝福 |

マスコットと祝福は **4**。1〜3を邪魔したら出しすぎ。

## デザイン案の二層

| 順 | 層 | 例 |
|----|-----|-----|
| 1 | 配置・部品・UI/UX | 主ボタンの位置、一覧の密度、余白 |
| 2 | 色の割り当て | どのテーマパック／セマンティック役割を使うか |

3案比較の主差は **1**。色だけで3コピーを作らない。

## トーン

対象イメージ（2026時点の調査要約）: **20〜30代の大人の推し活** — 熱量は高く、見た目はスマート。  
**日常に溶けるニュートラルな器 × 推し色・写真で熱を出す。** ティーン向けファンシー全面は避ける。

| 目指す | 避ける |
|--------|--------|
| 柔らかく清潔・中庸のかわいさ | 全面ピンク／全面パープル固定 |
| 写真が映える余白 | 枠・バッジ・絵文字の多用 |
| 短いやさしいコピー（[voice.md](voice.md)） | 専門用語だらけ・煽り・幼児語 |
| 短い・分かりやすいモーション | 長い演出・常時パーティクル・本線の遊び尽くし |
| 紙・ソフトシャドウ・薄いガラスの「宝物」感 | ガチャ光沢・ネオン一辺倒・極端なかわいさ |
| 手書き・ナイーブは感情点だけ | UI 全体を落書き・手書きフォントだらけ |
| マスコットは **庇護欲×くらげ同質の大人お洒落画風**（[mascot-asset-brief.md](mascot-asset-brief.md)、正参照はくらげ idle） | キッズ画風、またはかわいさを消した冷たい顔だけ |
| 自分用の聖域感（シェア強要しない） | SNS前提の公開CTAを本線に置く |

## AI 定番見た目（禁止寄り）

次を「ブランドの顔」にしない（既存の frontend 方針とも一致）:

- 紫〜インディゴのグラデ一辺倒  
- クリーム地＋セリフ＋テラコッタ定番セット  
- 新聞風の細い罫線レイアウト  

## 形・質感・タイポ（方針）

詳細の数値は [tokens.md](tokens.md)。アイコン線は [icons.md](icons.md)。

| 層 | Do | Don't |
|----|-----|-------|
| 角 | 中庸の角丸（丸すぎ・角ばりすぎない） | pill 乱用・ゼロ半径の硬さだけがブランド |
| 質感 | 紙・木目の気配・ソフトシャドウ・薄いガラス | 全面ネオングラス／強い光沢で情報を邪魔 |
| タイポ | 見出しはやわらかいゴシック or 上品な丸ゴ（Rounded はロゴ・見出しのみ）。本文はすっきりサンセリフ | 手書きフォントの多用・本文セリフ固定 |
| 装飾 | ナイーブ／手書きは空状態・祝福など感情点のみ | 画面全体を「かわいいデコ」にする |

## 感情演出の予算（出現条件）

**実装前でも守る。** 詳細な長さは [motion.md](motion.md)。文言は [voice.md](voice.md)。

| 演出 | 出してよいとき | 出してはいけないとき |
|------|----------------|----------------------|
| マスコット（場面） | 空状態・404・（任意）待ちの大きめ差し替え | 一覧の全カード、常時ヘッダー、フォーム脇の常駐 |
| マスコット（parts） | スピナー／バー／インライン待ち・短い完了 | 装飾だけのループ常時表示 |
| 祝福（celebrate） | 登録完了・意味のある達成など **スポット** | 保存のたびに毎回・画面遷移のたび |
| パーティクル／キラキラ | **本線では使わない** | — |
| 手書き・ナイーブ装飾 | 感情点のコピー付近のみ | ナビ・設定一覧全体 |

トーン強度（下表）で出現頻度を変えてよいが、**階層1〜3を侵さない**。

## トーン強度（落ち着き ／ 推し活フル）

テーマ色パック（[themes.md](themes.md)）とは **別軸**。色の一式ではなく、**装飾・マスコット・推し色の強さ**を切り替える。  
**実装前でも、案・Lab・文言でこの差分を破るな。**

| 項目 | 落ち着き | 推し活フル |
|------|----------|------------|
| ねらい | おしゃれ・日常・店頭でも違和感少 | 熱量・祭壇寄り・自分空間 |
| マスコット | 出さない／小さめ／感情点のみ | 空・待ち・祝福で出しやすい |
| 推し色 | 控えめ（またはオフ寄り） | ボタン・面で強く出してよい |
| 装飾・祝福 | 最小 | スポット祝福は可（予算内） |
| 本線機能 | **同じ**（登録・検索・タグは消さない） | **同じ** |

| 項目 | 方針 |
|------|------|
| モード名 | **落ち着き**／ **推し活フル**（「隠しモード」禁止） |
| 本線の切替 | **手動トグル**（今どのモードかが分かる） |
| 時間・曜日の自動 | **任意・既定オフ**。手動が優先 |
| 設定の置き場（案） | `/settings/theme` で色・マスコットと並べるが **別コントロール** |
| 採用状態 | 方針 accepted（fb-006）。設定 UI・API は未着手（明示の実装承認後） |

## Do / Don't（短く）

| Do | Don't |
|----|-------|
| shadcn 部品 + CSS 変数一式 | 画面に `#RRGGBB` を直書き |
| テーマでトークン全体を切替 | 「primary/ring だけ」の差し替えを正にする |
| 見た目変更は3案比較してから本番 | いきなり全画面を1案で書き換え |
| カラータグは製品ラベルとして維持 | カラータグ＝アプリテーマ色に統合する |
| 既定は緑系 `default` | Dash/Bootswatch テーマ名を正にする |
| 器はニュートラル、熱は推し色・写真 | アプリ全体を原色かわいい一色にする |
| 強度モードは手動本線 | スケジュール自動だけに依存する |
| コピーは [voice.md](voice.md) | 煽り・幼児語・絵文字だらけ |
| 階層は写真が先 | マスコット／バッジで写真を潰す |
