# デザイン原則

推し活グッズ管理アプリ向け。対象は「今どきの推し活ユーザー」が気持ちよく使えること。  
**女性らしさ・推し活感は、色の決め打ちではなく UI/UX と動きで作る。**

## 原則（5つ）

1. **写真とグッズが主役** — 装飾より中身。ギャラリーは大きく、余白をケチらない。  
2. **やさしく、でも信頼できる** — かわいいだけで終わらせない。登録・設定は迷わず進める。  
3. **推し色はアクセント** — 背景ごと塗り替えない。ボタン・フォーカス・小さな目印に使う。**用途最適案でも推し色は入れる。**  
4. **1画面・1仕事** — 次にやることが一目で分かる。ヘッダーに機能を詰め込みすぎない。  
5. **触って分かる** — 押下・保存・切替は短い動きで返す。派手な演出はしない。

## デザイン案の二層

| 順 | 層 | 例 |
|----|-----|-----|
| 1 | 配置・部品・UI/UX | 主ボタンの位置、一覧の密度、余白 |
| 2 | 色の割り当て | primary / 推し色 / muted をどこに使うか |

3案比較の主差は **1**。色だけで3コピーを作らない。

## トーン

| 目指す | 避ける |
|--------|--------|
| 柔らかく清潔 | 全面ピンク／全面パープル固定 |
| 写真が映える余白 | 枠・バッジ・絵文字の多用 |
| 短いやさしいコピー | 専門用語だらけの説明 |
| 軽いモーション | 強い bounce・グロー・点滅 |

## AI 定番見た目（禁止寄り）

次を「ブランドの顔」にしない（既存の frontend 方針とも一致）:

- 紫〜インディゴのグラデ一辺倒  
- クリーム地＋セリフ＋テラコッタ定番セット  
- 新聞風の細い罫線レイアウト  

## Do / Don't（短く）

| Do | Don't |
|----|-------|
| shadcn 部品 + CSS 変数 | 画面に `#RRGGBB` を直書き |
| 推し色はスウォッチで選ばせる | テーマ名だけの長いセレクトを主UIにする |
| 見た目変更は3案比較してから本番 | いきなり全画面を1案で書き換え |
| カラータグは製品ラベルとして維持 | カラータグ＝アプリ推し色に統合する |
