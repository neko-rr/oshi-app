# DoD: ダッシュボード

- [ ] `/dashboard` が開ける（ログイン必須）
- [x] チャート／集計用 API（`/dashboard/charts` 等）を呼べる
- [x] データが空でもエラーで真っ白にならない
- [x] カラータグの付与件数・割合を円とバーで見られる（1グッズに複数タグがあるときはそれぞれ加算。ゲストは本登録案内）
- [x] グッズの色（固定15色・複数可）の件数を、色の丸つきの棒で見られる。件数がある色だけ。色なしの件数も出す。棒からその色のギャラリーへ移れる。カラータグとは別
- [x] 所持・欲しい・交換OKの件数が見られ、ギャラリーの同じ条件へ移れる
- [x] カテゴリと収納の件数内訳が見られ、その絞り込みのギャラリーへ移れる
- [x] 購入価格は通貨ごとに合計する（換算しない）。価格なしの件数も出す
- [x] 月ごとの支出は購入日の暦月。日付のない品は別枠。空の月は作らない。直近12か月まで
- [x] 予算は通貨ごとの毎月同じ上限で、今月の支出と比べる。超えた分は残りの数字で出す
- [x] 推し何日目はキャラ名ごとに開始日を持つ。その日を1日目にする。未来の開始日は日数を出さない
- [x] 価格なし・購入日なし・月の行から、同じ条件のギャラリーへ移れる
- [x] カテゴリなし・収納なしの件数から、そのギャラリーへ移れる
- [x] 写真なしの件数から、写真が無いグッズのギャラリーへ移れる（差し替えは詳細）
- [x] 同じバーコードが2件以上の件数から、そのグッズのギャラリーへ移れる。空の番号は数えない
- [x] 収納は入る枚数と現在件数を比べる。入る枚数は収納場所の設定で変える
- [ ] 通貨の換算、月ごとに違う予算、カテゴリ予算、推し部屋はしない
