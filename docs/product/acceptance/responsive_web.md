# DoD: スマホ対応 Web（responsive_web）

- [x] `lg` 未満で下部タブ（ギャラリー／登録／検索／その他）から本線へ届く（スマホ横向き含む）
- [x] `lg` 以上では下部タブを出さず、トップナビで同等の到達性がある
- [x] 認証画面では下部タブを出さない
- [x] 縦・横どちらでもタブがコンテンツを隠さない（余白・safe-area）
- [x] 横向きではタブが圧縮され、最初の本線コンテンツが見える
- [x] 「その他」から設定・分析・ログアウト・法務へ届く
- [x] ギャラリー選択モード時、一括バーが下部タブと重なって操作不能にならない
- [x] 詳細ヒーローは横向きでも横長写真が判別できる（object-contain）
- [x] 一覧は横向きビューポートでカードが極端に縦長のままにならない

関連: `responsive_web`
