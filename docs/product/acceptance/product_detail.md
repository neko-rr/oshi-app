# DoD: 製品詳細

- [x] `/gallery/[registered_product_id]` で自分の製品を開ける
- [x] 他人の ID は見えない／エラーになる（RLS・API）
- [x] 名前・メモ・価格など基本項目を編集して保存できる
- [x] タグ・収納など関連項目を編集して保存できる
- [x] 関連写真があれば表示できる
- [x] 「← ギャラリー」が一覧のクエリ（検索・タグ絞込・offset）を保持する
- [x] 写真を主役に閲覧でき、その下（または折りたたみ）で編集できる
- [x] 写真をタップ／拡大でフルスクリーン表示し、ピンチまたは +/- で拡大確認できる
- [x] 保存成功時に短い成功フラッシュが出る
- [x] 保存失敗時（オフライン／電波弱含む）に再試行導線がある
- [x] 一覧から開いたとき、隣の製品へスワイプまたは前後ボタンで連続確認できる

関連: `product_detail` / `gallery_detail_neighbors`
