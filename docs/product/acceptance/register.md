# DoD: 製品登録

- [x] `/register` で名前など必須項目を入れて登録できる
- [x] 写真なしでも本保存できる（任意アップロード）
- [x] バーコード番号入力から照合アシストを呼べる（キー未設定時は落ちない）
- [x] 登録後、ギャラリーに自分の製品が見える
- [x] ウィザード（1→2→6）で進められる（カメラ読取・Vision LIVE は任意／未設定可）
- [x] バーコードをカメラまたは画像から読める（失敗時は番号入力）
- [x] 読取後、同じバーコードが自分のリストにあればヒント表示（追加登録は妨げない）
