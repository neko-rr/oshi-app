# DoD: 製品登録

- [x] `/register` で名前など必須項目を入れて登録できる
- [x] 写真なしでも本保存できる（任意アップロード）
- [x] バーコード番号入力から照合アシストを呼べる（キー未設定時は落ちない）
- [x] 登録後、ギャラリーに自分の製品が見える
- [x] ウィザード（1→2→6）で進められる（カメラ読取・Vision LIVE は任意／未設定可）
- [x] バーコードをカメラまたは画像から読める（失敗時は番号入力）
- [x] 読取後、同じバーコードが自分のリストにあればヒント表示（追加登録は妨げない）
- [x] 写真あり時に Vision 1回で見た目タグ・種類提案を呼べる（LIVE オフ／キー未設定でも落ちない）
- [x] バーコードで埋まった商品名・価格は Vision で上書きしない（手入力も優先）
- [x] 購入価格に記録通貨（ISO）を選べる（既定は居住地。価格なしでは保存しない）
- [x] 登録成功後に「続けて登録」で設定した開始手順に戻れる（主CTA。作品シリーズ・キャラ・購入日・収納・カテゴリ・色・通貨を引き継ぎ）
- [x] 確認画面で「詳しく」に Oshi／数量フラグ／購入詳細／URL を折りたたみ、必須・照合・タグは常時表示できる
- [x] 確認画面（成功後含む）の「全部消す」でイベント束・タグ束をクリアできる（製品名など他項目は残る）
- [x] `/settings/register` で開始手順（barcode / photo / confirm）と「いつも選ぶ収納」を設定できる
- [x] いつも選ぶ収納あり → 確認画面で選択済み＋チップ先頭。なし → 登録回数順（自動選択なし）
- [x] バーコード／手動スキップ後に「次からこの手順」の提案が出る（セッション中1回）
- [x] 楽天 2026 API（applicationId + accessKey）でバーコード／キーワード照合できる（LIVE オフでも落ちない）
- [x] 写真選択直後にプレビューが見られ、撮り直しできる
- [x] 写真は選択時にアプリ用へ軽くされ、API の 10MB 上限を超えない（失敗時は分かりやすいエラー）
- [x] 選択時に EXIF 向きを直し、プレビューで左右に 90° 回転できる
- [x] スキャナが全幅寄りで、横向きでも枠と CTA が被らない
- [x] 登録成功時に短い成功フラッシュが出る
- [x] API 失敗時（オフライン／電波弱含む）に再試行導線がある
- [x] ゲストはウィザード画面を進められるが、写真アップロード・照合・Assist・本保存は本登録ゲートになる
- [x] 楽天照合成功時、先頭候補で名・価格・外部参照を自動入力し、確認画面の候補リスト（最大5）から差し替えできる（手入力欄は上書きしない）
- [x] 楽天候補を選んだとき `product_url` / `external_item_code` / `shop_name` が `product_external_ref`（source=`rakuten`）として本保存される（スキップ登録では楽天行なしで可）
- [x] メルカリ等の任意URL（source=`manual`・任意ラベル）を登録確認で入力・保存できる
- [x] 製品詳細の編集で外部参照（楽天必須セット／任意URL）を表示・変更できる
- [x] 製品詳細の閲覧側で主リンク（`is_primary`）をワンタップで開ける
- [x] 作品シリーズ名・タイトル・購入日を登録・詳細で編集できる
- [x] 所持数・交換OK（フラグ＋個数）・欲しいフラグを登録・詳細で編集できる
- [x] `/settings/register` で手元に残す数と「余剰を交換OKにする」を設定できる（個別手調整後は自動上書きしない）
- [x] 同じグッズ（バーコードまたは楽天 item_code）の所持ヒントに件数・合計所持数が出る（追加登録は妨げない）
- [x] 確認画面からキーワードで楽天検索し、候補を登録欄へ反映できる

後続（Must 本線外）: 店頭専用購入済み画面、一括／CLIP、交換OK一覧フィルタ・交換画面。
