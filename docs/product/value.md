# 顧客価値（正本）

推し活グッズ（BOX・ガチャ・書籍など）を、**実物の収納とデータの一覧をつないで管理しやすくする**アプリ。

## 提供する価値

1. **早く登録できる** — バーコードや正面写真から、可能な範囲で製品情報・タグを自動提案する。
2. **実物とデータがつながる** — 収納場所タグで「どこにあるか」を残し、一覧・検索でたどり着ける。
3. **推しの世界観に合わせられる** — テーマ色など、見た目を自分の推し色に寄せられる。
4. **自分のデータは自分のもの** — テナントは `members_id`（ログインユーザー）。他人のグッズは見えない（RLS）。

## 非交渉（エージェントも守る）

- 認証発行は **Supabase Auth のみ**。API は **JWKS**。
- 業務ロジックは **`apps/api` の services**。Web/Mobile にドメインを埋め込まない。
- アップロード写真を **学習用に外部へ渡して再学習させない**旨を、プライバシー方針で明示する（実装時も守る）。
- 秘密・service_role・JWT 秘密をクライアントに載せない。

## スコープの境界

| 中核 | 後回し（要求されてから） |
|------|--------------------------|
| 登録・一覧・詳細・タグ・収納・テーマ | SNS シェア、推し部屋、規約・退会の本実装、書籍専用フローの大拡張 |
