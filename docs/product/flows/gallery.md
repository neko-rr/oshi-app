# フロー: ギャラリー（一覧・詳細）

登録済みグッズを **写真主役** で眺め、タグやキーワードで探し、詳細で編集して戻る。  
対象は Web（`/gallery`）。Mobile は後続。

## 一覧 `/gallery`

1. ログイン必須。自分の製品だけ（RLS + API）。
2. グリッド／大きめ／リストは見た目設定の `gallery_layout`（設定画面）。
3. **検索 `q`**: 製品名・カテゴリ名・収納名の部分一致。**ページを跨いで正確**（DB 側フィルタ後に limit/offset）。
4. **チップ絞り込み**（複数可）:
   - カテゴリ / 収納 / 色（スロット）
   - **同種は OR、異種は AND**
   - URL: `category_tag_id=1,2` / `storage_location_id=…` / `color_tag_slot=1,3`（単一 ID も互換）
   - **クエリ版** `v=1`: 同種 OR・異種 AND の契約。パラメータがあるときだけ付与（API には送らない）。当面版上げしない
   - **いまの条件**: 上部に件数要約（例: カテゴリ2・収納1・色1。検索語ありなら「検索」も）＋一発クリア（並びは残す）
5. **並び**: 一覧上で newest / name / created_at。URL `sort` に載せ、同時に `display_settings.list_sort` も更新。
6. **保存ビュー**（無料・上限20）: いまの条件（検索・タグ・並び）に名前を付けて保存。タップで `v=1` クエリへ適用。削除可。表 `gallery_view`（JSON 黒箱なし）。
7. **もっと見る**: `has_more` が true のとき次ページ（同フィルタで offset 加算）。
8. **一括更新**: 「選択」→ 範囲操作（このページ全選択／条件結果を最大100件選択／選択した N 件だけ表示）→ カードを選ぶ → **収納**または**カテゴリ**を変更（`PATCH /products/bulk`）。クリア（なし）も可。
9. カードタップ → 詳細（選択モード中は選択切替）。リンクに現在の一覧クエリを引き継ぐ。
10. 空状態: 未登録なら登録へ CTA。絞込ゼロ件なら条件クリアの案内。
11. 登録直後 `?registered=` で軽い成功メッセージ可。

URL 状態の例: `/gallery?v=1&category_tag_id=1,2&storage_location_id=3&color_tag_slot=1&sort=name`

## 詳細 `/gallery/[registered_product_id]`

1. 自分の製品のみ。他人は 404（存在漏洩しない方針）。
2. 写真（高解像度優先）→ メタ → 編集。編集機能は落とさない。
3. 「← ギャラリー」は **一覧にいたときのクエリを復元** する（絞込・並び・offset）。

## 検索ページとの関係

ギャラリー内の `q` が一覧検索の DoD。`/search` の全面刷新はスコープ外だが、同じ `GET /products` を流用してよい。

## やらない（このフロー）

- ギャラリー画面内のレイアウト／カード項目クイック切替（設定が本線）
- Mobile 専用画面
- 一覧上でのインライン編集（詳細で編集）
- 100件超の一括（上限は API と UI で揃え、超分は絞り込み／分割で対応）
