# フロー: ギャラリー（一覧・詳細）

登録済みグッズを **写真主役** で眺め、タグやキーワードで探し、詳細で編集して戻る。  
対象は Web（`/gallery`）。Mobile は後続。

## 一覧 `/gallery`

1. ログイン必須。自分の製品だけ（RLS + API）。
2. グリッドでサムネを表示（署名 URL 失敗時も一覧は壊れない）。
3. **検索 `q`**: 製品名・カテゴリ名・収納名の部分一致。**ページを跨いで正確**（DB 側フィルタ後に limit/offset）。
4. **チップ絞り込み**: カテゴリ / 収納のマスターから選び、`category_tag_id` / `storage_location_id` で AND。
5. **もっと見る**: `has_more` が true のとき次ページ（同フィルタで offset 加算）。
6. カードタップ → 詳細。リンクに現在の一覧クエリを引き継ぐ。
7. 空状態: 未登録なら登録へ CTA。絞込ゼロ件なら条件クリアの案内。
8. 登録直後 `?registered=` で軽い成功メッセージ可。

URL 状態の例: `/gallery?q=&category_tag_id=&storage_location_id=&offset=`

## 詳細 `/gallery/[registered_product_id]`

1. 自分の製品のみ。他人は 404（存在漏洩しない方針）。
2. 写真（高解像度優先）→ メタ → 編集。編集機能は落とさない。
3. 「← ギャラリー」は **一覧にいたときのクエリを復元** する。

## 検索ページとの関係

ギャラリー内の `q` が一覧検索の DoD。`/search` の全面刷新はスコープ外だが、同じ `GET /products` を流用してよい。

## やらない（このフロー）

- Dash の thumb/list 切替
- Mobile 専用画面
- 一覧上でのインライン編集（詳細で編集）
